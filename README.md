# IATC website – bản xem trước

Bản nháp trang chủ iatcvn.com (tiếng Việt và tiếng Anh) để BOD duyệt giao diện.

- `index.html`: trang chủ tiếng Việt
- `en/index.html`: trang chủ tiếng Anh

Đã gắn `noindex, nofollow`: Google không đưa vào kết quả tìm kiếm.
Form và nút thanh toán chưa hoạt động. Website chính thức sẽ dựng trên WordPress (AZDIGI).
